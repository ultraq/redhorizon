
JOML extensions
===============

[![Maven Central](https://img.shields.io/maven-central/v/nz.net.ultraq.redhorizon/joml-extensions)](https://central.sonatype.com/artifact/nz.net.ultraq.redhorizon/joml-extensions)

Extensions to JOML objects to make some operations easier.


Installation
------------

Requires Java 25 on either macOS 12 Monterey and newer or Windows 10 64-bit and
newer.

Add a dependency to your project with the following co-ordinates:

 - GroupId: `nz.net.ultraq.redhorizon`
 - ArtifactId: `joml-extensions`
 - Version: `0.43.1`

Check the [project tags](https://github.com/ultraq/redhorizon/tags) for a list
of available versions.
